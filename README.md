# ROAD TO BENQ

Mobilna aplikacja oszczędnościowa na monitor **BenQ ZOWIE XL2566X+ 400 Hz**.

## Funkcje
- Cel oszczędnościowy: 2 600 zł.
- Pasek postępu, kwota pozostała, liczba wpłat i średnia wpłata.
- Dodawanie wpłat z datą i opisem.
- Ostatnie wpłaty.
- Dane zapisywane lokalnie w pamięci przeglądarki urządzenia.
- Układ dostosowany do iPhone'a oraz instalacja jako PWA.

## Publikacja
Projekt zawiera workflow GitHub Actions w `.github/workflows/pages.yml`.
W repozytorium otwórz **Settings → Pages**, ustaw **Source: GitHub Actions**. Po zapisaniu GitHub uruchomi wdrożenie. Adres strony będzie:
https://minek1522icloud-beep.github.io/ROAD-TO-BENQ/

## Prywatność danych
Wpłaty są przechowywane w localStorage przeglądarki. Nie są wysyłane do repozytorium ani na serwer. Wyczyść dane witryny lub użyj innej przeglądarki/urządzenia, a zapisane wpłaty nie będą dostępne.
